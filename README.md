# Noor Atelier

Modern Arabic fashion storefront with interactive product discovery, cart behavior, and responsive shopping flows.

## Live Demo

- Live: https://fleepatef42-sudo.github.io/fashion-store-Noor-Atelie/
- Source: https://github.com/fleepatef42-sudo/fashion-store-Noor-Atelie

## Features

- Product grid with category, size, and price filtering.
- Search and quick-view interactions.
- Add-to-cart, quantity updates, subtotal, shipping message, and cart drawer behavior.
- Dark mode and saved UI preferences.
- Newsletter form feedback.
- Responsive Arabic UI for desktop and mobile screens.

## Tech Stack

- HTML5
- CSS3
- JavaScript
- LocalStorage
- Lucide icons
- Unsplash image assets

## Project Note

This is a client-side e-commerce UI demo. Cart and preferences are stored locally in the browser.
